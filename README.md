# Tello UAV Vision and Control Projects

This repository contains Python projects developed for a UAV/drone class using the DJI Tello Talent drone.

The work includes basic drone setup tests, camera stream tests, manual keyboard teleoperation, hover stability tests, and a final computer vision project where the drone follows a person wearing a light green shirt using OpenCV color masks.

## Project Structure

```text
01_setup_tests/
Basic connection, battery, and video delay tests.

02_manual_control/
Keyboard teleoperation with live camera stream.

03_hover_tests/
Simple hover stability tests.

04_green_shirt_follower/
Final vision-based project using OpenCV HSV masks to detect and follow a green shirt.

docs/
Reports and project documentation.

media/
Screenshots or demo images.
